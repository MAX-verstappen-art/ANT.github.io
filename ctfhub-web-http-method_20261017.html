CTFHub HTTP Method Writeup

分类：Web | 考点：自定义 HTTP 请求方法 | 更新时间：2026-10-17

题目描述

题目提示使用特殊的 HTTP 请求方法访问页面。抓包后发现浏览器当前使用的是 GET 方法，而题目要求使用 CTFHUB 方法访问 index.php。

考点

  • HTTP 请求方法
  • $_SERVER['REQUEST_METHOD']
  • 405 Method Not Allowed

思路分析

HTTP 协议并不限制请求方法只能是 GET、POST、PUT 等标准方法。后端 PHP 可以通过 $_SERVER['REQUEST_METHOD'] 获取客户端使用的请求方法。

这道题的核心逻辑是：当请求方法等于 CTFHUB，并且直接访问 index.php 时，后端返回 flag。

提示：如果直接使用自定义方法访问根路径 /，可能会触发 405 Method Not Allowed。题目提示说明，应直接请求 /index.php。

解题过程

1. 使用 Burp Suite 捕获浏览器访问靶场的请求。

2. 将原始请求行：

GET / HTTP/1.1

修改为：

CTFHUB /index.php HTTP/1.1

3. 将修改后的请求发送到 Repeater，点击发送，即可在响应中得到 flag。

Python 脚本验证

使用 requests 发送自定义 HTTP 方法：

import requests

url = "http://challenge-f3c04b4c0404356b.sandbox.ctfhub.com:10800/index.php"
resp = requests.request(method="CTFHUB", url=url)

print(resp.status_code)
print(resp.text)

总结

  • HTTP 请求方法可以自定义，后端会按 REQUEST_METHOD 的值进行判断。
  • 遇到 405 时，除了修改方法，还要注意题目是否要求访问特定文件。
  • Burp Suite 的 Repeater 适合用来调试和验证这类 HTTP 方法逻辑。
