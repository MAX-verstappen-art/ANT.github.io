Bugku-MISC｜这是一张单纯的图片

平台：Bugku CTF｜题型：MISC｜考点：文件尾部追加与 HTML 实体编码

题目信息

  • 平台：Bugku CTF
  • 题型：MISC
  • 题目描述：这是一张单纯的图片，找到 flag。
  • 附件：一张 jpg 图片文件

解题思路

这道题属于文件追加考点。出题人没有修改图片本身内容，直接在 jpg 文件的最末尾，追加了一段 HTML 十进制实体编码字符串。

编码格式为 &#数字;，浏览器渲染会自动解析解码，但是查看网页源代码看到的仍是原始编码字符，无法直接搜索 key{，需要使用解码工具还原出明文 flag。

详细解题过程

步骤 1：下载附件

拿到题目提供的 jpg 图片。

Windows 系统默认隐藏已知文件扩展名，这是高频坑点，需要先在文件资源管理器设置中取消该选项，否则修改后缀不会生效。

步骤 2：修改文件后缀

把 .jpg 修改为 .html。

双击使用浏览器打开该文件，图片会正常显示在页面上。

步骤 3：查看网页源代码

浏览器页面快捷键 Ctrl + U，打开 view-source 源代码窗口。

页面绝大部分内容是 jpg 图片的二进制乱码。

直接按键盘 End 键，跳转到源代码文档最底部，得到一长串 HTML 十进制实体编码。

步骤 4：实体编码解码

复制底部那一大段 &#xxx; 实体编码，使用 HTML 实体解码器解码，即可得到最终 flag。
