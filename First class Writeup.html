# Bugku CTF 头等舱 Writeup ## 题目信息 - 平台：Bugku CTF - 分类：Web - 题目：头等舱 ## 题目现象 访问页面，页面显示：`什么也没有。` 查看网页源代码，无flag，页面无其他内容。 ## 考察点 读取HTTP响应头。 > 题目名字“头等舱”提示：看HTTP头部(Header)，不是网页内容。 ## 解题步骤 ### 方式一：浏览器F12开发者工具 1. 访问靶场链接，按`F12`打开开发者工具 2. 切换到 `网络(Network)` 选项卡 3. `F5`刷新页面，捕获请求 4. 点击列表中第一条 document 请求 5. 在右侧面板切换至 **响应头(Response Headers)** 6. 在头部列表找到自定义flag字段，取值即为flag ### 方式二：curl命令快速获取头部 ```bash curl -I 靶场URL
