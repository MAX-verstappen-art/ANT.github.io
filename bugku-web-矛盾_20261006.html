矛盾

WEB | Bugku

题目描述

PHP代码审计，两个条件逻辑看似互相矛盾，利用PHP弱类型绕过。

考点

PHP 弱类型比较，== 松散比较，0与字符串比较

解题过程

1.审计源码，需要同时满足两个看似冲突的判断条件。

2.PHP中字符串与数字使用==时，字符串会强制转为数字，以非数字开头字符串会转为0。

3.构造payload传入GET参数，满足两边条件，获取flag。

# payload示例
?num=@%00

Flag

flag{php_weak_compare_bug}

总结踩坑

区分 == 松散比较 和 === 严格比较，严格比较不会触发弱类型漏洞。
