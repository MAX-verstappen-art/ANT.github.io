一、题目分析

题目名为“瑞士军刀”，在网络安全领域通常指代 Netcat(nc) 工具。 题目描述仅有一个 ls，提示我们需要连接靶机并执行系统命令。 这是一道入门级 PWN 题，考察基础的 Linux 命令和 Netcat 工具使用。

二、解题过程与环境踩坑

阶段1：Windows PowerShell直接尝试

首先在 Windows PowerShell 中直接使用 nc 连接靶机：

nc 160.202.254.160 14273

✅踩坑：Windows原生PowerShell没有nc命令，直接执行会提示不是内部命令。

阶段2：切换WSL / Kali Linux环境

使用WSL或者Kali终端，系统自带netcat，执行连接命令：

nc 160.202.254.160 14273

成功连上远程靶机，拿到交互式shell。

阶段3：执行Linux命令获取flag

  1. 输入 ls 查看当前目录文件，发现flag文件
  2. 输入 cat flag 读取flag文件内容
  3. 复制输出得到flag，提交平台完成解题

三、踩坑总结

  • Windows默认不带netcat工具，不要在PowerShell直接跑nc，建议WSL/Kali。
  • nc命令IP和端口空格分隔，不能写冒号。
  • 靶机场景存在存活时间，超时需要重新开启，IP端口会变化。
  • 文件名就叫flag，不要写cat flag.txt，会报文件不存在。

四、考点总结

  • Netcat(nc)网络工具基础使用，理解“网络瑞士军刀”含义
  • 基础Linux命令 ls、cat
  • 远程交互式shell基础操作
