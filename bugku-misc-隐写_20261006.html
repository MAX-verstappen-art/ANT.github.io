隐写

MISC | Bugku

题目描述

下载一张PNG图片，打开图片大部分空白，图片CRC校验报错，需要修改PNG IHDR块高度，还原图片拿到flag。

考点

PNG文件结构，IHDR块宽高修改，图片CRC校验原理。PNG文件头第16字节开始是宽度(4字节)，之后4字节是高度。

解题过程

1. 下载图片，使用010Editor / WinHex打开图片，查看IHDR块。

2. 发现图片高度字段被修改，导致图片显示不全，CRC校验失败。

3. 将高度十六进制 01 A4 修改为 01 F4，保存文件。

4. 重新打开图片，图片完整显示，底部出现flag。

# Python自动修复PNG高度并重新计算CRC
import binascii
import struct

img = open("test.png","rb").read()
# IHDR块偏移位置
ihdr = img[12:29]
width = struct.unpack('>I', ihdr[0:4])[0]
height = struct.unpack('>I', ihdr[4:8])[0]
print(f"原宽:{width},原高:{height}")

# 修改高度为0x01F4
new_height = 0x01F4
new_ihdr = struct.pack('>I', width)+struct.pack('>I', new_height)+ihdr[8:]
new_crc = binascii.crc32(new_ihdr) & 0xffffffff

# 拼接新图片
new_img = img[:12] + new_ihdr + struct.pack('>I',new_crc) + img[29:]
open("fixed.png","wb").write(new_img)
print("已生成修复后的 fixed.png")

Flag

BUGKU{a1e5aSA}

总结踩坑

只修改高度不更新CRC校验值，图片依然无法正常打开；可以使用在线PNG宽高修复工具快速验证。
