这不是md5

CRYPTO | Bugku

题目描述

给了一段密文，提示：这不是md5，仔细观察字符集。

考点

MD5字符集过滤，剔除不属于md5的非法字符，剩下的字符就是flag。

解题过程

1. MD5只包含0‑9,a‑f，其他字符全部为干扰。

2. 遍历密文，只保留0123456789abcdef，丢弃其余字符。

cipher = "密文粘贴在这里"
md5_charset = set("0123456789abcdef")
res = []
for c in cipher:
    if c in md5_charset:
        res.append(c)
print(''.join(res))

3. 输出结果就是flag。

Flag

flag{xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx}

总结踩坑

不要直接拿去md5解密，题目名字已经提示“这不是md5”，重点是筛选合法字符。
