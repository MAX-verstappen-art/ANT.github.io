Bugku‑Crypto‑你以为是md5吗

题目信息

平台：Bugku CTF

分类：Crypto

提示：md5的构成

描述：flag{}

考点

MD5哈希字符集知识：md5结果仅由 0‑9,a‑f 16个字符组成。剔除字符串中非法字符得到真实md5，再进行md5解密。

解题步骤

  1. 下载附件md5，得到密文：bci177a7a9c7udf69c248647b4dfc6fd84o
  2. MD5合法字符：0123456789abcdef，去掉非法字符 i、u、o
  3. 得到纯净md5：bc177a7a9c7df69c248647b4dfc6fd84
  4. 使用在线md5解密网站解密，得到明文：666666666666

Python过滤脚本

s = "bci177a7a9c7udf69c248647b4dfc6fd84o"
md5_set = set("0123456789abcdef")
res = [c for c in s if c in md5_set]
print(''.join(res))

Flag

flag{666666666666}

踩坑记录

  • ❌ 误区：提取非法字符作为flag。
  • ✅ 正确：剔除非法字符，拿到真实md5，解密md5得到flag。
