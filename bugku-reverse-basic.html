Bugku‑Reverse｜入门逆向

题目信息

  • 平台：Bugku CTF
  • 题型：Reverse 逆向
  • 题目：入门逆向
  • 难度：新手入门

解题原理（重点：为什么是这个 flag）

这道题的 flag不是写在字符串段里。程序运行时，在 main 函数内通过汇编指令，逐个把 flag 每个字符的 ASCII 字节压入栈，在栈上动态拼凑出完整 flag。直接看字符串窗口找不到内容。

需要读取汇编代码中的十六进制字节，转换 ASCII 字符拼接，最终得到 flag。

解题步骤

  1. 题目页面下载 exe 附件，拿到可执行程序。
  2. DIE 工具检测：32位无壳 PE 程序。
  3. IDA Pro(32位)打开程序，跳转至 main 函数。
  4. 阅读汇编，提取压栈的十六进制序列： 
    66h 6Ch 61h 67h 7Bh 52h 65h 5Fh 31h 73h 5Fh 53h 30h 5Fh 43h 30h 4Fh 7Dh
  5. 逐个十六进制转 ASCII，顺序拼接得到：flag{Re_1s_S0_C0OL}
  6. 将 flag 提交平台完成答题。

坑点

  • C0OL：中间的 0 是数字零，不是大写字母O；末尾 L 是大写L，极易混淆，写错直接提交错误。
  • Re_1s：中间的 1 是数字1，不是小写字母 l。
  • Shift+F12 字符串窗口看不到flag，flag运行时才在栈上构造。

考点总结

  • 静态逆向基础，读懂栈上逐字节构造字符串汇编代码
  • ASCII码与十六进制互相转换
  • 区分视觉相似字符：数字0/1，大写字母O/L
