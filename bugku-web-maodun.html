Bugku Web｜矛盾

题目信息

  • 平台：Bugku CTF
  • 类型：Web PHP弱类型
  • 题目链接：http://160.202.254.160:19590

源码

$num=$_GET['num'];
if(!is_numeric($num))
{
echo $num;
if($num==1)
echo 'flag{**********}';
}

考点

PHP弱类型比较 ==，is_numeric()函数绕过。

解题思路

两个矛盾条件：
1. !is_numeric($num)：传入参数不能是纯数字字符串
2. $num ==1：弱比较等价等于数字1
payload ?num=1a，字符串1a不是纯数字，但是PHP做弱比较时，会提取开头数字1和数字1相等，两个条件同时满足。

解题步骤

  1. 访问题目原始链接
  2. GET传参，构造payload：?num=1a
  3. 完整URL：http://160.202.254.160:19590/?num=1a
  4. 页面直接输出flag
