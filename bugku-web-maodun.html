作者：陆楷中

题目描述

Web基础CTF题目，页面直接给出PHP源码，考察PHP函数 is_numeric() 的弱类型绕过。

源码分析

$num=$_GET['num'];
if(!is_numeric($num))
{
    echo $num;
    echo 'flag{**********}';
}

逻辑：GET传入参数num，如果 is_numeric() 判断不为数字，就输出num变量和flag。

is_numeric() 只会判断是否为纯数字，我们传入数字+字母组合，即可绕过。

解题思路

构造GET参数，让 num 的值为数字加字母，例如 1a。

Payload：

?num=1a

访问靶机

完整URL：http://160.202.254.160:19590/?num=1a

页面输出：1aflag{baaea44448d54fd4dfe722e1e171be20}

前面的 1a 是传入的参数，是回显的垃圾内容，真正flag在后面大括号内。

Flag

flag{baaea44448d54fd4dfe722e1e171be20}

踩坑记录

  • 靶机会动态刷新，每次重启flag哈希串会改变，不要使用网上旧的固定flag字符串；
  • 提交flag必须使用大括号 { }，不能写成圆括号 ( )；
  • 不要复制多余空格、顿号等符号，多余字符会直接判定flag错误。
