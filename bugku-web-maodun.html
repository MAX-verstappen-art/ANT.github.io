Bugku Web｜矛盾

题目信息

  • 平台：Bugku CTF
  • 类型：Web PHP弱类型审计
  • 分值：10
  • 题目链接：http://160.202.254.160:19590

源码

$num=$_GET['num'];
if(!is_numeric($num))
{
echo $num;
if($num==1)
echo 'flag{**********}';
}

考点

PHP弱类型比较 ==，is_numeric()函数绕过。
is_numeric()判断是否为数字/数字字符串；双等号==会自动做类型转换。

解题思路

两个看起来互相矛盾的条件：
1. !is_numeric($num)：传入参数不能是纯数字字符串，才能进入代码块。
2. $num ==1：弱比较结果必须等于数字1。
payload ?num=1a：字符串1a不是纯数字，满足条件1；PHP和数字对比时，自动截取开头数字1，"1a" ==1结果为true，满足条件2。

解题步骤

  1. 访问题目原始页面，查看源代码得到PHP代码
  2. URL拼接GET参数构造payload：?num=1a
  3. 完整访问链接：http://160.202.254.160:19590/?num=1a
  4. 页面输出内容：1aflag{bugku-789-ps-ssdf}
