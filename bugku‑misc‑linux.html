题目描述

给了一个压缩包附件，寻找flag。

解题步骤

  1. 下载附件 linux.zip。
  2. 使用unzip解压zip包： 
    unzip linux.zip
    解压得到 linux/ 文件夹，里面是 1.tar.gz。
  3. 解压tar压缩包： 
    cd linux
tar -zxvf 1.tar.gz
ls
    得到 test/ 目录。
  4. 进入test目录，使用strings读取镜像文件可读字符串： 
    cd test
strings flag
  5. 输出内容中包含回收站Trash元数据，提取MD5哈希字符串： 
    key{feb81d3834e2423c9903f4755464060b}
  6. 对MD5值 feb81d3834e2423c9903f4755464060b 进行解密，得到明文flag。

考点分析

  • 多层压缩包嵌套解压（zip + tar.gz）
  • strings 工具提取二进制镜像内可读字符串
  • Linux ext文件系统回收站 .Trash 元数据信息泄露
  • MD5哈希解密
