Bugku‑散乱的密文 Writeup

题目信息

  • 题目名称：散乱的密文
  • 题目类型：Crypto
  • 题目描述：一段被打乱顺序的密文，找出原始flag

解题思路

题目给出分组置换规则：**6位分组置换**，含义为每6个字符作为一组，按照顺序 2 1 6 5 3 4 进行位置打乱。

加密下标（从0开始）加密顺序：[1, 0, 5, 4, 2, 3]

加密时每组原位置：0→1，1→0，2→5，3→4，4→2，5→3

想要解密，需要推导逆置换，将每组字符还原顺序，最后剔除干扰字符，得到flag。

密文

cipher = "If5{ag024c483549d7fd@1}"

Python解密EXP

cipher = "If5{ag024c483549d7fd@1}"
# 加密顺序 [1,0,5,4,2,3]，求逆置换
encrypt_order = [1, 0, 5, 4, 2, 3]
# 构造解密逆映射
decrypt_order = [0]*6
for plain_idx,cipher_idx in enumerate(encrypt_order):
    decrypt_order[cipher_idx] = plain_idx

res = ""
# 按6字符分组
for i in range(0, len(cipher), 6):
    block = cipher[i:i+6]
    if len(block) == 6:
        new_block = ''.join([block[x] for x in decrypt_order])
        res += new_block
    else:
        res += block

print(res)

脚本运行结果

flag{024ac4835497dfd1}

原理说明

1.加密：明文块 [p0,p1,p2,p3,p4,p5] → 根据 encrypt_order[1,0,5,4,2,3]，输出 [p1,p0,p5,p4,p2,p3]（密文块）

2.解密：拿到密文块，使用逆置换 decrypt_order，把密文每个位置放回原始明文位置。

3.分组结束后剩余不足6位的字符直接拼接，最后得到完整flag。
