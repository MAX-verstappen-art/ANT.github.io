Ook! Brainfuck 解密

作者：陆楷中 | 解题日期：2026-09-24

题目信息

  • 平台：BugkuCTF
  • 类型：Crypto
  • 考点：Ook! → Brainfuck 转换与执行
  • Flag：
FLAG flag{bugku_jiami}

解题思路

Ook! 是一种基于 Brainfuck 的趣味晦涩语言，它使用 Ook.、Ook?、Ook! 的组合来表示 Brainfuck 的 8 种指令。因此解题的核心不是直接分析字符，而是先将 Ook! 转换为标准 Brainfuck，再解释执行得到明文。

关键思路：Ook! 只是 Brainfuck 的“外壳”，必须先转成 Brainfuck，再运行解密。

步骤 1：识别 Ook! 密文

题目给出的密文由大量 Ook.、Ook?、Ook! 组成，需要按每两个一组进行解析。

步骤 2：Ook! 转 Brainfuck

Ook! 指令与 Brainfuck 指令存在固定映射关系：

Ook. Ook.  →  >
Ook. Ook?  →  <
Ook? Ook.  →  +
Ook? Ook?  →  -
Ook! Ook.  →  .
Ook. Ook!  →  ,
Ook! Ook?  →  [
Ook? Ook!  →  ]

步骤 3：执行 Brainfuck

将转换后的 Brainfuck 代码输入解释器运行，最终输出明文 Flag。

Python 解密脚本

def ook_to_brainfuck(ook):
    tokens = ook.split()
    code = []
    mapping = {
        ('Ook.', 'Ook.'): '>',
        ('Ook.', 'Ook?'): '<',
        ('Ook?', 'Ook.'): '+',
        ('Ook?', 'Ook?'): '-',
        ('Ook!', 'Ook.'): '.',
        ('Ook.', 'Ook!'): ',',
        ('Ook!', 'Ook?'): '[',
        ('Ook?', 'Ook!'): ']',
    }
    for i in range(0, len(tokens), 2):
        code.append(mapping[(tokens[i], tokens[i+1])])
    return ''.join(code)


def run_brainfuck(code):
    tape = [0] * 30000
    ptr = 0
    pc = 0
    output = []
    stack = []
    bracket_map = {}

    for i, c in enumerate(code):
        if c == '[':
            stack.append(i)
        elif c == ']':
            start = stack.pop()
            bracket_map[start] = i
            bracket_map[i] = start

    while pc < len(code):
        c = code[pc]
        if c == '>':
            ptr += 1
        elif c == '<':
            ptr -= 1
        elif c == '+':
            tape[ptr] = (tape[ptr] + 1) % 256
        elif c == '-':
            tape[ptr] = (tape[ptr] - 1) % 256
        elif c == '.':
            output.append(chr(tape[ptr]))
        elif c == ',':
            tape[ptr] = ord(input()[0])
        elif c == '[' and tape[ptr] == 0:
            pc = bracket_map[pc]
        elif c == ']' and tape[ptr] != 0:
            pc = bracket_map[pc]
        pc += 1

    return ''.join(output)


ook_code = """Ook! Ook. Ook? Ook. Ook! Ook! ..."""
bf_code = ook_to_brainfuck(ook_code)
flag = run_brainfuck(bf_code)
print(flag)

运行结果

flag{bugku_jiami}

原理说明

  • Ook! 以两个符号为一组，每组对应一个 Brainfuck 指令。
  • Brainfuck 基于纸带模型，通过指针移动和字节增减实现计算。
  • 遇到循环指令 [ 和 ] 时，需要预先建立括号映射，才能正确跳转。
  • 最终输出是 ASCII 字符流，拼接后得到明文 Flag。

总结

这道题的关键是识别 Ook! 与 Brainfuck 的等价关系，并利用脚本完成自动转换与执行。遇到类似趣味加密语言时，不要直接做字符频率分析，而应先判断它属于哪种晦涩语言，再按对应解释模型处理。
