MD5杂谈

CRYPTO | Bugku

题目描述

给出混杂非法字符的字符串，过滤不属于md5字符集的字符，得到纯净md5哈希值解密。

考点

字符过滤，MD5解密，字符集识别

解题过程

1.MD5合法字符：0‑9，a‑f。其余全部删除。

2.过滤掉密文中其他乱码符号，得到32位md5。

3.使用在线md5解密平台，解密得到明文，生成flag。

#Python简单过滤示例
md5_chars = set("0123456789abcdef")
clean = ''.join([c for c in cipher if c in md5_chars])
print(clean)

Flag

flag{filter_md5_success}

总结踩坑

必须严格只保留0‑9 a‑f，多余符号会导致解密失败。
