头等舱

WEB | Bugku

题目描述

页面提示只有头等舱用户可以访问，需要修改请求头信息来通过校验。

考点

HTTP请求头伪造，User-Agent / Referer / Cookie 等请求头修改

解题过程

1. 访问页面，提示不是头等舱用户，拒绝访问。

2. 使用BurpSuite抓包，修改HTTP请求头，添加或者修改对应的请求头字段。

3. 添加请求头：X-Forwarded-For: 1.1.1.1 或者修改头等舱相关自定义Header，发送数据包。

4. 服务器识别请求头，校验成功，返回flag。

# 修改后的请求头示例
X-Forwarded-For: 1.1.1.1

Flag

flag{first_class_http_header}

总结踩坑

很多Web题目会校验HTTP请求头，客户端发送的请求头都可以任意伪造，不能作为身份认证依据。
